# 旧书 OG → 2.0 DB 速查

| 原书 OG | DB 主线 |
|---|---|
| 块引用 `((UUID))` | Node `[[...]]` |
| 块嵌入 `{{embed ((UUID))}}` | `/Node embed` |
| `#tag` 旧式行内标记 | `#Tag` / Tag Properties / `Cmd-Enter` 选择行内 |
| `template::` | `#Template` + `/Template` |
| `NOW`/`LATER`/`DONE` | `#Task` + Status、Deadline、Scheduled |
| `{{query ...}}` | `/Query` Builder |
| 旧 Datalog | `/Advanced Query`，schema 已变 |
| 旧图谱 | Graph View V2 |
| Whiteboard 白板 | DB 内置白板已移除 |
| Markdown 文件目录为图谱真源 | SQLite 数据库为真源；标准 Markdown 导出不完整 |

详见主指南附录 A、B，遇到差异先核对版本，不要使用旧语法强行调试。
