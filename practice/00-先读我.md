# Logseq 2.0 DB 学习包｜开始前

- 适用软件：Logseq 2.0.2 **Beta**（DB 图谱），不是 OG。
- **本压缩包是教程与输入素材，不是完整 SQLite 图谱，不应直接作为 DB graph 导入。**
- 先阅读主指南；在 Logseq 2.0 中新建 `SecondBrain-Book-DB-Lab` 独立本地图谱。
- 手动创建实验页面；每次输入一到两条样例，再完成操作。
- 用《练习验收表.md》追踪每个任务；出现界面差异时填《差异与问题记录.md》。
- 不要在 Beta 图谱放账号密码、私密资料或重要生产数据。
- 首次按书学习先不启用 MCP、Sync 或插件。

版本来源：https://github.com/logseq/logseq/releases/tag/2.0.2
